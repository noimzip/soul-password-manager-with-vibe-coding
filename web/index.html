主な機能

cloud_sync

クラウド同期

Googleアカウントでログインすれば、すべてのデバイスでパスワードがリアルタイムに同期されます。データは暗号化されて保存されます。

fingerprint

Passkey 対応

Face IDやTouch IDなどの生体認証を使って、マスターパスワードを入力せずに安全にログインできます。

security

漏洩チェック

Have I Been Pwned APIと連携し、パスワードが過去に漏洩していないか安全にチェックします（k-Anonymity対応）。

password

強力な生成ツール

解読困難なランダムパスワードを瞬時に生成。強度メーターと推定解読時間も表示します。

timer

TOTP 認証

2段階認証（2FA）用のワンタイムパスワード生成機能を内蔵。別のアプリを開く必要はありません。

lock_clock

自動ロック

一定時間操作がない場合、自動的に保管庫をロックして覗き見を防ぎます。

堅牢なセキュリティアーキテクチャ

encrypted AES-256 暗号化

データは保存される前に、AES-GCM (256ビット) を使用してローカルで暗号化されます。平文のパスワードがデバイスの外に出ることはありません。

key PBKDF2 鍵導出

マスターパスワードは、一意のソルトを使用したPBKDF2（100,000回の反復）によって強化され、強力な暗号化キーが生成されます。

visibility_off ゼロ知識証明

私たちはあなたのマスターパスワードを知りません。サーバーには暗号化されたデータのみが保存され、復号できるのはあなただけです。
