# Soul Password Manager - Browser Extension

**パスワード自動入力のためのブラウザ拡張機能**

このブラウザ拡張機能は、Soul Password Managerと連携して、Webサイトのログインフォームにパスワードを自動入力します。

## 機能

- 🔍 **フォーム自動検出**: ログインフォームを自動的に検出
- 🔑 **ワンクリック入力**: パスワードフィールドに表示されるSoulアイコンをクリックして入力
- 🎯 **スマートマッチング**: 現在のURLに基づいて関連するパスワードを自動提案
- 🔒 **セキュア通信**: Soul PWAとの安全な通信
- 💾 **オフラインキャッシュ**: パスワードリストをキャッシュして高速アクセス

## インストール方法

### Chrome / Edge

1. Chrome/Edgeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `extension` フォルダを選択

### Firefox

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」をクリック
3. `extension` フォルダ内の `manifest.json` を選択

## 使い方

### 初回セットアップ

1. Soul Password Manager (PWA) を開いてログイン
2. ブラウザ拡張機能がインストールされていることを確認
3. ログインフォームのあるWebサイトにアクセス

### パスワードの自動入力

#### 方法1: Soulアイコンから入力

1. ログインフォームのパスワードフィールドに🔑アイコンが表示されます
2. アイコンをクリック
3. 表示されるポップアップから使用するパスワードを選択
4. 自動的にフォームに入力されます

#### 方法2: 拡張機能アイコンから入力

1. ブラウザのツールバーにあるSoul拡張機能アイコンをクリック
2. パスワードリストから選択
3. 自動的にフォームに入力されます

#### 方法3: 右クリックメニュー

1. フォーム内で右クリック
2. 「Fill with Soul Password Manager」を選択
3. パスワードリストから選択

## セキュリティ

- **ゼロナレッジ**: 拡張機能はパスワードを保存しません
- **キャッシュ**: パスワードリスト（タイトル、ユーザー名、URL）のみキャッシュ
- **実際のパスワード**: 入力時のみPWAから取得
- **同一オリジン通信**: 信頼されたオリジン（PWA）のみと通信

## トラブルシューティング

### パスワードが表示されない

1. Soul PWAが開いていてログインしていることを確認
2. 拡張機能ポップアップの「Refresh」ボタンをクリック
3. ブラウザの拡張機能ページで拡張機能を再読み込み

### フォームに入力されない

1. パスワードフィールドが正しく検出されているか確認
2. ページを再読み込み
3. Firefoxの場合、コンテンツスクリプトの権限を確認

### PWAとの通信ができない

1. PWAのURLがmanifest.jsonの `externally_connectable` に含まれているか確認
2. ブラウザコンソールでエラーを確認
3. ローカル開発の場合、`http://localhost:5173/` が許可されているか確認

## 開発

### ローカル開発

```bash
# PWAの開発サーバーを起動
npm run dev

# ブラウザで拡張機能を読み込む
# Chrome: chrome://extensions/ → デベロッパーモード → パッケージ化されていない拡張機能を読み込む
```

### デバッグ

- **Content Script**: Webページのコンソール（F12）で確認
- **Background Script**: 拡張機能ページ → 「Service Worker」のリンクをクリック
- **Popup**: ポップアップ上で右クリック → 検証

### ログの確認

拡張機能のすべてのログには `[Soul AutoFill]` プレフィックスが付きます。

## 制限事項

- PWAが開いていないと初回は動作しません（キャッシュがある場合は動作）
- クロスオリジンiframe内のフォームは検出されません
- 一部の動的に生成されるフォームは検出に時間がかかる場合があります
